# <img src="/readme.files/icon-512.png" alt="icon" title="imagine" width="40" height="40" align="left" /> Imagine - Make it smaller

Imagne let you reduce your image sizes. Just in two simple step; Choose image and compress it...</br>
You can download a signed apk from [**latest release**](https://github.com/alibardide-dev/Imagine/releases/latest)

## Features
- Compress Images
- Minimal UI

## Image Quality
It does a pretty good job compressing image, with little to none data loss

## Tech Stack
- **Android**, obviously
- **Kotlin** for android programming

## Setup
- Clone this repository by running `https://github.com/alibardide-dev/Imagine.git`
- Download and Install Android Studio and Android SDK
- Install Android Virtual Machine or connect a Physical Device
- Run project using Shift + F10
